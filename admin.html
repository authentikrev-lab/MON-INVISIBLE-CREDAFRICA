🎲 Gestion des tirages par site

Seuls les salariés n’ayant pas encore consulté leur Invisible peuvent changer d’attribution. Les associations déjà découvertes sont conservées.

Cette opération modifie réellement les Invisibles des salariés non consultés du site choisi. Elle ne peut pas être annulée depuis cette page.

➕ Ajouter un collaborateur

Inscription et attribution immédiate. Les attributions déjà consultées restent inchangées.

Cette opération est définitive. Elle est refusée si aucune attribution non consultée n'est disponible sur le site.

✏️ Modifier un collaborateur

Cliquez sur « Modifier » dans le tableau. Une date de naissance laissée vide reste inchangée. Un transfert de site est soumis à des contrôles de sécurité côté serveur.

Si le site change, le serveur vérifie les attributions déjà découvertes. Si un autre salarié a déjà découvert la personne transférée, le transfert est refusé afin de protéger son tirage. Une consultation du salarié transféré peut être réinitialisée après archivage sécurisé.
